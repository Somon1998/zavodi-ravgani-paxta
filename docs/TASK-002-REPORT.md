# TASK #002 — Соответствие утверждённому макету

## Итог

Существующий сайт переработан точечно. Стек, конфигурация контента, фотографии, логотип, SEO-маршруты и логика меню сохранены. Изменены стили и композиция главной страницы; существующие тесты расширены. Публикация не выполнялась, другие проекты не изменялись.

## Сравнение с оригиналом

Ориентир: references/approved-design.png. Сравнивалась композиция сайта внутри экрана ноутбука, без окружающего рекламного изображения и рамки устройства.

| Элемент | До | После |
| --- | --- | --- |
| Header на десктопе | 94 px | 76 px, логотип слева, меню по центру, кнопка справа |
| Hero при ширине 1440 px | 590 px | 400 px |
| Hero на телефонах | минимум 680 px | минимум 530 px, высота может расти с содержимым |
| Производственные карточки на десктопе | минимум 270 px | минимум 170 px, одинаковые пропорции |
| О заводе | большой декоративный блок и широкие отступы | короткий текст, переход к производству и три компактных визуальных элемента |
| Продукция | крупная презентационная секция | компактный каталог: заголовок слева, одна карточка справа |

Сохранены зелёно-золотая палитра, промышленный Hero, тёмный градиент, бело-золотой заголовок, две кнопки и золотая волна. Уменьшены вертикальные расстояния. В каталоге изображение показывается целиком через object-fit: contain; на телефонах изображение и описание располагаются вертикально. Маркировка иллюстраций сохранена.

На 1366×768 виден весь блок «О заводе» и начало производственных карточек. Кнопки Hero имеют высоту не менее 44 px.

## Осознанные отличия от макета

- Одна карточка хлопкового масла вместо четырёх видов масла: остальные виды не подтверждены, дубли не создавались.
- Вместо неподтверждённых преимуществ показаны местоположение, направление продукции и подготовка к открытию.
- Сохранены существующие фотографии и временный хлопковый знак. Они отличаются от изображений и логотипа на макете.
- Сохранены подписи о демонстрационном характере изображений, раздел контактов и footer.
- На мобильных устройствах карточки идут вертикально, чтобы сохранить читаемость и изображение продукта целиком.
- Пиксельное совпадение с рекламным изображением не заявляется: тексты, состав продукции, фотографии и пропорции экрана отличаются.

## Проверки

- npm run lint — успешно, без ошибок и предупреждений ESLint.
- npm run typecheck — успешно.
- npm run build — успешно; статические маршруты созданы.
- npm run test:e2e — 9 тестов прошли, финальный запуск 12,4 секунды.
- Размеры: 320, 375, 390, 768, 1024, 1366, 1440, 1920 px. Для десктопов высота окна 768 px, для остальных — 900 px.
- Проверены горизонтальное переполнение, загрузка изображений, цели якорных ссылок, меню, Escape и возврат фокуса, переходы, отсутствие ошибок JavaScript, одна карточка продукции, SEO и локальные ресурсы.
- Визуально проверены desktop, mobile и tablet скриншоты; композиция сравнена с оригиналом.

Найденное переполнение на 320 и 1024 px было вызвано автоматическим расчётом ширины карточек из aspect-ratio и min-height. Исправление: явная width: 100% и min-width: 0. Ошибка не скрывается через overflow-x: hidden. После исправления все проверки прошли.

Технические особенности среды: сборке потребовался запуск вне песочницы из-за EPERM при записи .next. Проверку типов после конфликта генерации .next/types повторили последовательно после сборки — успешно.

Проверки выполнены в Microsoft Edge через Playwright. Реальные мобильные устройства, Safari и Firefox отдельно не проверялись.
