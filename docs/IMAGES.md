# Изображения

Все изображения сайта временные, сгенерированы встроенным image_gen. Не являются фотографиями предприятия заказчика, реальной продукцией или подтверждением оборудования/упаковки. Маркировка присутствует на странице. Исходный макет используется только как референс, а не как фотография сайта.

Оптимизированные файлы: public/images/hero.webp (1536 px), product.webp (1000 px), cotton.webp, seeds.webp, oil.webp (700 px). Последние три — тематические кадрирования натюрморта. Итоговый размер всех WebP около 390 КБ. Next Image дополнительно отдаёт подходящие размеры экрану.
