Из карточек производства больше не выводятся:

- `/images/cotton.webp` — «Хлопковое растение»;
- `/images/seeds.webp` — «Сырьё для производства»;

- изображение `public/images/vakhsh-sanoat-product.webp` (1000×666, WebP, `object-contain`);

- подзаголовок «Равғани пахта»;

Повтор одного макета в соседних блоках исключён. Характеристики с этикетки (объём, срок, стандарт) в текст сайта не переносились.
