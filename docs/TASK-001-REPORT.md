# Отчёт TASK #001

Дата: 19 ноября 2026 года.

## Создано

Адаптивный корпоративный сайт в корне C:/zavodi-ravgani-paxta: Header, мобильное меню, Hero, О заводе, Производство, одна карточка хлопкового масла, Контакты, Footer. Централизованная конфигурация в src/data/site.ts. SVG-знак хлопка с каплей масла, favicon, SEO, robots, sitemap, скрипт QR-кода. Админка, база данных, оплата и сбор персональных данных отсутствуют.

## Соответствие макету

Сохранены белая навигация, зелёно-золотая палитра, производственная иллюстрация справа, крупный заголовок слева, две кнопки, золотая волна, информационный раздел и три карточки. Отступы увеличены для удобства чтения. Неподтверждённые преимущества и четыре вида масла из примера заменены достоверным содержимым и одной карточкой хлопкового масла. Фото реального завода не имитируются без пояснения: демонстрационные изображения подписаны.

- Проверены отсутствие пустых контактных ссылок, единственный H1, заголовок страницы, отсутствие ошибок JavaScript и ошибок console.
- Главная, robots.txt, sitemap.xml, favicon.ico, icon.svg и SVG-логотип отвечают HTTP 200.

- Скриншоты 390 и 1440 px просмотрены визуально. Скриншоты всех проверенных ширин: artifacts/screenshots/.

Проверки выполнялись на Windows в Chromium/Edge. Safari, Firefox, реальные устройства, Lighthouse и QR-сканирование не проверялись.

## Исправленная проблема сборки

Turbopack завершал дочерний процесс обработки CSS до подключения. Повтор вне изоляции дал ту же ошибку. Использованы поддерживаемый Next.js параметр --webpack и Tailwind PostCSS. Production build после этого прошёл. Браузерным тестам потребовался запуск вне песочницы и отдельный порт 3100 из-за ограничений локальных соединений среды.
