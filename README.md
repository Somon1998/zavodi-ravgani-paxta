# Маслозавод — TASK #001

Корпоративный сайт нового предприятия в Бохтаре. Создан непосредственно в корне пустого проекта. Публикация не выполнялась.

## Локальный запуск

Требуется Node.js 22 или новее.

```powershell
npm ci
npm run dev
```

Открыть http://localhost:3000. Для production-режима: `npm run build`, затем `npm start`.

## Проверки

```powershell
npm run lint
npm run typecheck
npm run build
npm run test:e2e
```

Браузерные тесты используют установленный Microsoft Edge. На другой машине установите Edge либо замените `channel` в playwright.config.ts на доступный браузер. Тесты запускают production-сервер; перед ними нужна сборка. Скриншоты сохраняются в artifacts/screenshots.

## Где менять содержимое

- `src/data/site.ts` — название, подпись, путь к логотипу, описание, навигация, продукция, контактные данные.
- `src/components/layout/` — Header, Footer, мобильное меню.
- `src/components/sections/home.tsx` — разделы главной страницы.
- `src/app/globals.css` — палитра и адаптивная вёрстка.
- `public/logo/cotton.svg` — оригинальный временный знак: хлопок, листья и капля масла.
- `src/app/icon.svg`, `src/app/favicon.ico` — favicon; обновить вместе с официальным логотипом.
- `public/images/` — оптимизированные демонстрационные WebP-изображения.
- `references/approved-design.png` — утверждённый визуальный ориентир.
- `docs/IMAGES.md` — происхождение иллюстраций и промпты.
- `scripts/generate-qr.mjs` — QR-код после подключения официального домена.
- `tests/site.spec.ts` — проверки адаптивности, навигации, изображений и SEO.

Пустые контакты автоматически скрываются. WhatsApp указывается в международном формате; ссылка формируется только из цифр. Не добавлять неподтверждённые сведения.

## Технологии и сборка

Next.js App Router 16.4.6, React 19.3, TypeScript, Tailwind CSS 4.3, Next Image, ESLint, Playwright. Точные установленные зависимости зафиксированы package-lock.json.

В этой Windows-среде Turbopack завершал дочерний процесс CSS до подключения. Поэтому dev/build используют официальный параметр `--webpack`, Tailwind подключён через PostCSS. См. https://nextjs.org/docs/app/api-reference/cli/next .

## Подготовка к Vercel

Проект готов к стандартному Next.js deployment: корень репозитория, `npm run build`, Node.js 22+. Публикация только после отдельного разрешения заказчика. До коммерческого запуска отдельно проверить актуальные условия тарифа Vercel для предприятия; в рамках этой задачи тариф не выбирался.

После получения реального адреса скопировать .env.example в .env.local и задать NEXT_PUBLIC_SITE_URL=https://реальный-домен; на Vercel добавить эту переменную в настройки окружения и пересобрать проект. Это включит canonical, полную Open Graph-картинку, индексацию и реальный URL в sitemap.xml. Без переменной robots запрещает индексацию, sitemap пустой. Временные preview-развёртывания рекомендуется оставлять без этой переменной.

## QR-код

После подключения официального HTTPS-домена:

```powershell
npm run qr -- https://официальный-домен
```

Результат: artifacts/site-qr.svg. Временные адреса *.vercel.app отклоняются. Окончательный QR-код пока не создан. Перед печатью проверить адрес и сканирование несколькими телефонами.
